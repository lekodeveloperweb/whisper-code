# Whisper-Code

**Voice dictation for macOS — hands-free, local, private.**

Whisper-Code is a lightweight background utility that converts your spoken words into text and seamlessly inserts them into your active application. No keyboard required.

## Key Features

- 🚀 **Focus-Stable HUD**: Ghost HUD strategy keeps your cursor in place
- 🎤 **Local API**: Works with oMLX and any OpenAI-compatible server
- 📋 **Smart Injection**: Uses macOS Accessibility API to paste at cursor
- 💎 **Glassmorphic Design**: Modern translucent visual feedback with live waveform
- ⚙️ **Settings Dialog**: Configure everything from the tray menu
- ⚡ **Native Performance**: Optimized for Apple Silicon via MLX

## Privacy

- **100% Local**: No audio data ever leaves your machine
- **In-Memory**: Audio chunks are processed and discarded; nothing saved to disk
