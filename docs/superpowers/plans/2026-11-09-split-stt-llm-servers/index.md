# Plan: Split STT and LLM Servers + Per-Server API Keys

**Spec:** docs/superpowers/specs/2026-11-09-split-stt-llm-servers-design.md

**Goal:** Four config keys — `stt_api_url`, `stt_api_key`, `llm_api_url`,
`llm_api_key` — let the transcription and grammar paths target different
OpenAI-compatible servers, each sending `Authorization: Bearer <key>` only
when its own key is set. `api_url` / `WHISPER_API_URL` are removed (hard
rename, user-approved).

**Global Constraints (1:1 from spec `## Constants`):**

- `AUTH_HEADER_FORMAT = "Authorization: Bearer {key}"  # wire format for both servers, exercised by AC-10`
- `EMPTY_KEY_MEANS_NO_AUTH = None | "" ⇒ {}  # keeps local no-auth servers working, exercised by AC-11, AC-13, AC-14`
- `STT_URL_DEFAULT = "http://localhost:8080"  # pre-existing default under its new key name, exercised by AC-1, AC-2, AC-8`
- `LLM_URL_FALLBACK = stt_api_url  # unset/empty llm_api_url reuses the STT server, exercised by AC-6, AC-7`
- `LEGACY_KEYS_DROPPED = api_url | WHISPER_API_URL  # hard rename, no alias, exercised by AC-2`
- `NEW_CONFIG_DEFAULTS = llm_api_url | stt_api_key | llm_api_key = None  # "unset" sentinel, exercised by AC-1`
- `ENV_STT_API_URL = WHISPER_STT_API_URL  # env override name, exercised by AC-3`
- `ENV_LLM_API_URL = WHISPER_LLM_API_URL  # env override name, exercised by AC-5`
- `ENV_STT_API_KEY = WHISPER_STT_API_KEY  # env override name, exercised by AC-9`
- `ENV_LLM_API_KEY = WHISPER_LLM_API_KEY  # env override name, exercised by AC-9`

**Execution order:** tasks 1 → 7, strictly. Each task's gate runs its own
test file. KNOWN TRANSIENT FAILURES after task 4 (fixed by task 6, do NOT
"fix" them earlier): in `tests/test_settings_dialog.py`,
`test_settings_dialog_populates_from_config`,
`test_settings_dialog_cancel_does_not_save`, and
`test_settings_dialog_reject_button` fail (`_api_edit.text()` is `""` and
`saved["api_url"]` raises `KeyError` — the dialog still reads the dead
`api_url` key while `DEFAULT_CONFIG` no longer contains it).
